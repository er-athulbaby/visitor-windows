# Service Gate Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native Windows (WPF) app that replaces the paper book at a hotel service gate. Staff check service visitors in and out by CPR card, see who is inside and whose cards they hold, and admins get history, dashboard, settings and users.

**Architecture:** One WPF project on .NET 10 with code-behind screens that call a few plain service classes directly. Data lives in one local SQLite file accessed through EF Core; migrations upgrade each hotel's database on start. The CPR card reader is the vendor's local REST service, called with `HttpClient`. Translation is an English-keyed lookup with one `ar.json` file.

**Tech Stack:** C# / .NET 10 (`net10.0-windows`), WPF, EF Core SQLite, LiveCharts2 (dashboard chart), xUnit, Inno Setup 6.

**Spec:** `docs/superpowers/specs/2026-11-19-service-gate-design.md`

## Global Constraints

- Target framework `net10.0-windows`, `<Nullable>enable</Nullable>`, `<ImplicitUsings>enable</ImplicitUsings>`.
- WPF projects do **not** get `System.IO` as an implicit using. Add `using System.IO;` explicitly where `Path`, `File`, `Directory` or `MemoryStream` are used.
- Only allowed packages: `Microsoft.EntityFrameworkCore.Sqlite`, `Microsoft.EntityFrameworkCore.Design` (app); `LiveChartsCore.SkiaSharpView.WPF` (app, Task 12); the xUnit packages from the template (tests). Add nothing else.
- No network access except the card reader at the configured URL (default `http://localhost:5050/api/operation/ReadCard`).
- Database: `%ProgramData%\ServiceGatePass\gate.db`. Logs: `%ProgramData%\ServiceGatePass\logs\YYYY-MM-DD.log`.
- From the card, store only CPR, English name, Arabic name and employer. **Never store the photo**, address, passport, visa or biometrics.
- Every user-facing string goes through `L.T("English text")` (C#) or `{l:T 'English text'}` (XAML), with an Arabic entry in `src/ServiceGatePass/Resources/ar.json`. `TranslationCoverageTests` enforces this from Task 2 onward. XAML keys must not contain `'`.
- Times are local time (`DateTime.Now`), shown as `HH:mm` / `yyyy-MM-dd HH:mm`.
- Screens call services directly. No repository classes, no interfaces with one implementation, no MVVM framework.
- **Never commit real personal data** (real CPR numbers, names or photos) — not in fixtures, tests or screenshots.
- Shell: commands below are for Git Bash on Windows, run from the repo root `C:\Users\ababy\Desktop\Visitor-Windows`.

```csharp
using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Design;

namespace ServiceGatePass.Data;

public class GateDb(DbContextOptions<GateDb> options) : DbContext(options)
{
    public DbSet<Visitor> Visitors => Set<Visitor>();
    public DbSet<Visit> Visits => Set<Visit>();
    public DbSet<Location> Locations => Set<Location>();
    public DbSet<User> Users => Set<User>();
    public DbSet<Setting> Settings => Set<Setting>();

    public static DbContextOptions<GateDb> OptionsFor(string path) =>
        new DbContextOptionsBuilder<GateDb>().UseSqlite($"Data Source={path}").Options;

    protected override void OnModelCreating(ModelBuilder b)
    {
        b.Entity<Visitor>().HasIndex(v => v.Cpr).IsUnique();

        // "Inside now" = CheckOutAt IS NULL. These partial indexes make the database itself
        // refuse a second open visit per person, badge or slot.
        b.Entity<Visit>().HasIndex(v => v.VisitorId).IsUnique().HasFilter("CheckOutAt IS NULL");
        b.Entity<Visit>().HasIndex(v => v.BadgeNo).IsUnique().HasFilter("CheckOutAt IS NULL AND BadgeNo IS NOT NULL");
        b.Entity<Visit>().HasIndex(v => v.SlotNo).IsUnique().HasFilter("CheckOutAt IS NULL AND SlotNo IS NOT NULL");
        b.Entity<Visit>().HasIndex(v => v.CheckInAt);
        b.Entity<Visit>().HasOne(v => v.Location).WithMany().HasForeignKey(v => v.LocationId).OnDelete(DeleteBehavior.Restrict);

        b.Entity<User>().HasIndex(u => u.Username).IsUnique();
        b.Entity<Setting>().HasKey(s => s.Key);
    }
}

// Used only by `dotnet ef` at design time.
public class GateDbFactory : IDesignTimeDbContextFactory<GateDb>
{
    public GateDb CreateDbContext(string[] args) => new(GateDb.OptionsFor("design.db"));
}
```

```csharp
using System.Text.Json;
using System.Windows.Markup;

namespace ServiceGatePass;

/// English text is the key; Arabic comes from the embedded ar.json.
public static class L
{
    static Dictionary<string, string>? arabic;

    public static bool IsArabic { get; private set; }

    public static void Use(string lang)
    {
        IsArabic = lang == "ar";
        if (IsArabic && arabic == null)
        {
            using var stream = typeof(L).Assembly.GetManifestResourceStream("ar.json")
                ?? throw new InvalidOperationException("ar.json is not embedded.");
            arabic = JsonSerializer.Deserialize<Dictionary<string, string>>(stream)!;
        }
    }

    public static string T(string english) =>
        IsArabic && arabic!.TryGetValue(english, out var text) ? text : english;
}

/// XAML: {l:T 'Check in'}
[MarkupExtensionReturnType(typeof(string))]
public class TExtension : MarkupExtension
{
    public TExtension(string text) => Text = text;

    [ConstructorArgument("text")]
    public string Text { get; set; }

    public override object ProvideValue(IServiceProvider serviceProvider) => L.T(Text);
}
```

```csharp
using ServiceGatePass.Data;

namespace ServiceGatePass.Services;

public class SettingsStore(GateDb db)
{
    public const string HotelName = "HotelName";
    public const string LogoPath = "LogoPath";
    public const string BadgeEnabled = "BadgeEnabled";
    public const string SlotEnabled = "SlotEnabled";
    public const string SlotCount = "SlotCount";
    public const string BackupFolder = "BackupFolder";
    public const string ReaderUrl = "ReaderUrl";
    public const string Language = "Language";

    public string? Get(string key) => db.Settings.Find(key)?.Value;

    public void Set(string key, string? value)
    {
        var row = db.Settings.Find(key);
        if (value == null)
        {
            if (row != null) db.Settings.Remove(row);
        }
        else if (row == null) db.Settings.Add(new Setting { Key = key, Value = value });
        else row.Value = value;
        db.SaveChanges();
    }

    public bool GetBool(string key) => Get(key) == "1";

    public int GetInt(string key, int fallback) => int.TryParse(Get(key), out var v) ? v : fallback;
}
```

```csharp
using System.Security.Cryptography;

namespace ServiceGatePass.Services;

/// Stored as "base64(salt).base64(hash)", PBKDF2-SHA256, 100k iterations.
public static class PasswordHasher
{
    const int Iterations = 100_000;

    public static string Hash(string password)
    {
        var salt = RandomNumberGenerator.GetBytes(16);
        var hash = Rfc2898DeriveBytes.Pbkdf2(password, salt, Iterations, HashAlgorithmName.SHA256, 32);
        return $"{Convert.ToBase64String(salt)}.{Convert.ToBase64String(hash)}";
    }

    public static bool Verify(string password, string stored)
    {
        var parts = stored.Split('.');
        if (parts.Length != 2) return false;
        try
        {
            var salt = Convert.FromBase64String(parts[0]);
            var expected = Convert.FromBase64String(parts[1]);
            if (salt.Length == 0 || expected.Length == 0) return false;
            var actual = Rfc2898DeriveBytes.Pbkdf2(password, salt, Iterations, HashAlgorithmName.SHA256, expected.Length);
            return CryptographicOperations.FixedTimeEquals(actual, expected);
        }
        catch (FormatException) { return false; }
    }
}
```

```csharp
using ServiceGatePass.Data;

namespace ServiceGatePass.Services;

public class UserService(GateDb db)
{
    public const int MinPasswordLength = 6;

    public bool AnyUsers() => db.Users.Any();

    public List<User> All() => db.Users.OrderBy(u => u.Username).ToList();

    public User Create(string username, string displayName, string password, Role role)
    {
        var name = Normalize(username);
        if (name == "") throw new GateException(L.T("Username is required."));
        if (string.IsNullOrWhiteSpace(displayName)) throw new GateException(L.T("Display name is required."));
        CheckPassword(password);
        if (db.Users.Any(u => u.Username == name)) throw new GateException(L.T("That username is already taken."));

        var user = new User { Username = name, DisplayName = displayName.Trim(), PasswordHash = PasswordHasher.Hash(password), Role = role };
        db.Users.Add(user);
        db.SaveChanges();
        return user;
    }

    public User? Authenticate(string username, string password)
    {
        var name = Normalize(username);
        var user = db.Users.SingleOrDefault(u => u.Username == name);
        return user is { IsActive: true } && PasswordHasher.Verify(password, user.PasswordHash) ? user : null;
    }

    public void ResetPassword(int userId, string password)
    {
        CheckPassword(password);
        Get(userId).PasswordHash = PasswordHasher.Hash(password);
        db.SaveChanges();
    }

    public void SetActive(int userId, bool active)
    {
        var user = Get(userId);
        if (!active) GuardLastAdmin(user);
        user.IsActive = active;
        db.SaveChanges();
    }

    public void SetRole(int userId, Role role)
    {
        var user = Get(userId);
        if (role != Role.Admin) GuardLastAdmin(user);
        user.Role = role;
        db.SaveChanges();
    }

    void GuardLastAdmin(User user)
    {
        if (user.Role == Role.Admin && user.IsActive && db.Users.Count(u => u.Role == Role.Admin && u.IsActive) == 1)
            throw new GateException(L.T("At least one active admin is required."));
    }

    User Get(int id) => db.Users.Find(id) ?? throw new GateException(L.T("User not found."));

    static string Normalize(string username) => username.Trim().ToLowerInvariant();

    static void CheckPassword(string password)
    {
        if (password.Length < MinPasswordLength)
            throw new GateException(string.Format(L.T("Password must be at least {0} characters."), MinPasswordLength));
    }
}
```

```csharp
using Microsoft.EntityFrameworkCore;
using ServiceGatePass.Data;

namespace ServiceGatePass.Services;

public record CheckInRequest(string Cpr, string NameEn, string? NameAr, string? Employer, int LocationId,
    string? Company, string? Note, int? BadgeNo, int? SlotNo, int UserId);

public record InsideRow(int VisitId, string Name, string Cpr, string Location, DateTime CheckInAt, int? BadgeNo, int? SlotNo)
{
    public string Duration
    {
        get
        {
            var d = DateTime.Now - CheckInAt;
            return $"{(int)d.TotalHours}h {d.Minutes:00}m";
        }
    }
}

public class GateService(GateDb db, Func<DateTime>? clock = null)
{
    readonly Func<DateTime> now = clock ?? (() => DateTime.Now);

    public Visitor? FindVisitor(string cpr)
    {
        var c = cpr.Trim();
        return db.Visitors.SingleOrDefault(v => v.Cpr == c);
    }

    public Visit CheckIn(CheckInRequest r)
    {
        var cpr = r.Cpr.Trim();
        if (cpr.Length != 9 || !cpr.All(char.IsAsciiDigit)) throw new GateException(L.T("CPR must be 9 digits."));
        if (string.IsNullOrWhiteSpace(r.NameEn)) throw new GateException(L.T("Name is required."));
        var location = db.Locations.SingleOrDefault(l => l.Id == r.LocationId && l.IsActive)
            ?? throw new GateException(L.T("Pick a location."));

        // Friendly checks first; the partial unique indexes in GateDb are the backstop.
        var open = db.Visits.Where(v => v.CheckOutAt == null);
        var already = open.Include(v => v.Location).FirstOrDefault(v => v.Visitor.Cpr == cpr);
        if (already != null)
            throw new GateException(string.Format(L.T("Already inside at {0} since {1}."),
                already.Location.Display, already.CheckInAt.ToString("HH:mm")));
        if (r.BadgeNo is int badge && open.Any(v => v.BadgeNo == badge))
            throw new GateException(string.Format(L.T("Badge {0} is already in use."), badge));
        if (r.SlotNo is int slot && open.Any(v => v.SlotNo == slot))
            throw new GateException(string.Format(L.T("Slot {0} is already in use."), slot));

        var t = now();
        var visitor = FindVisitor(cpr);
        if (visitor == null)
        {
            visitor = new Visitor { Cpr = cpr, CreatedAt = t };
            db.Visitors.Add(visitor);
        }
        visitor.NameEn = r.NameEn.Trim();
        visitor.NameAr = Str.OrNull(r.NameAr) ?? visitor.NameAr;
        visitor.Employer = Str.OrNull(r.Employer) ?? visitor.Employer;
        visitor.LastCompany = Str.OrNull(r.Company);
        visitor.LastLocationId = location.Id;
        visitor.LastNote = Str.OrNull(r.Note);
        visitor.UpdatedAt = t;

        var visit = new Visit
        {
            Visitor = visitor,
            Location = location,
            Company = Str.OrNull(r.Company),
            Note = Str.OrNull(r.Note),
            BadgeNo = r.BadgeNo,
            SlotNo = r.SlotNo,
            CheckInAt = t,
            CheckInByUserId = r.UserId,
        };
        db.Visits.Add(visit);
        db.SaveChanges();
        return visit;
    }

    public void CheckOut(int visitId, int userId)
    {
        var visit = db.Visits.Find(visitId) ?? throw new GateException(L.T("Visit not found."));
        if (visit.CheckOutAt != null) throw new GateException(L.T("Already checked out."));
        visit.CheckOutAt = now();
        visit.CheckOutByUserId = userId;
        db.SaveChanges();
    }

    public List<InsideRow> Inside() =>
        db.Visits.Include(v => v.Visitor).Include(v => v.Location)
            .Where(v => v.CheckOutAt == null)
            .OrderBy(v => v.CheckInAt)
            .AsEnumerable()
            .Select(v => new InsideRow(v.Id, v.Visitor.NameEn, v.Visitor.Cpr, v.Location.Display, v.CheckInAt, v.BadgeNo, v.SlotNo))
            .ToList();

    public List<int> FreeSlots(int slotCount)
    {
        var used = db.Visits.Where(v => v.CheckOutAt == null && v.SlotNo != null).Select(v => v.SlotNo!.Value).ToHashSet();
        return Enumerable.Range(1, slotCount).Where(s => !used.Contains(s)).ToList();
    }
}
```

```csharp
using System.Text;
using System.Text.Json;

namespace ServiceGatePass.Services;

public record CardData(string Cpr, string NameEn, string? NameAr, string? Employer, string? ExpiryDate, string? PhotoBase64);

public record CardReadResult(CardData? Card, string? Error);

/// Talks to the vendor's "CIO GCC CardRead Server" REST service on this PC.
public class CardReader(HttpClient http, string url)
{
    public const string DefaultUrl = "http://localhost:5050/api/operation/ReadCard";

    const string RequestBody = """
        {"ReadCardInfo":false,"ReadPersonalInfo":true,"ReadAddressDetails":false,"ReadBiometrics":false,"ReadEmploymentInfo":true,"ReadImmigrationDetails":false,"ReadTrafficDetails":false,"SilentReading":false,"ReaderIndex":-1,"ReaderName":"","OutputFormat":"JSON","ValidateCard":false}
        """;

    public async Task<CardReadResult> ReadAsync(CancellationToken ct = default)
    {
        string json;
        try
        {
            using var timeout = CancellationTokenSource.CreateLinkedTokenSource(ct);
            timeout.CancelAfter(TimeSpan.FromSeconds(10));
            // The server parses the raw body, so send it as text/plain like the vendor sample does.
            using var response = await http.PostAsync(url, new StringContent(RequestBody, Encoding.UTF8, "text/plain"), timeout.Token);
            if (!response.IsSuccessStatusCode)
                return new(null, string.Format(L.T("Card reader returned HTTP {0}."), (int)response.StatusCode));
            json = await response.Content.ReadAsStringAsync(timeout.Token);
        }
        catch (HttpRequestException) { return NotRunning(); }
        catch (OperationCanceledException) when (!ct.IsCancellationRequested) { return NotRunning(); }

        return Parse(json);
    }

    static CardReadResult NotRunning() =>
        new(null, L.T("Card reader service is not running — start CIO GCC CardRead Server."));

    public static CardReadResult Parse(string json)
    {
        JsonElement root;
        try { root = JsonDocument.Parse(json).RootElement; }
        catch (JsonException) { return new(null, L.T("Card reader sent an unreadable reply.")); }

        // Errors come back as a normal response with ErrorDescription filled in.
        if (Text(root, "ErrorDescription") is string error) return new(null, error);

        var misc = root.ValueKind == JsonValueKind.Object && root.TryGetProperty("MiscellaneousTextData", out var m) ? m : default;
        var cpr = Text(root, "IdNumber") ?? Text(misc, "CPRNO");
        if (cpr == null) return new(null, L.T("No card detected. Enter CPR manually."));

        var name = Text(root, "EnglishFullName")
            ?? string.Join(" ", new[] { Text(root, "EnglishFirstName"), Text(root, "EnglishLastName") }.Where(s => s != null));
        var employer = Text(root, "EmployerName") ?? Text(root, "EmploymentNameEnglish") ?? Text(root, "SponserNameEnglish");

        return new(new CardData(cpr, name, Text(root, "ArabicFullName"), employer,
            Text(root, "CardexpiryDate"), Text(root, "PhotoB64Encoded")), null);
    }

    static string? Text(JsonElement e, string property) =>
        e.ValueKind == JsonValueKind.Object
        && e.TryGetProperty(property, out var v)
        && v.ValueKind == JsonValueKind.String
        && !string.IsNullOrWhiteSpace(v.GetString())
            ? v.GetString()!.Trim()
            : null;
}
```

```csharp
using Microsoft.EntityFrameworkCore;
using ServiceGatePass.Data;

namespace ServiceGatePass.Services;

public record HistoryFilter(DateTime From, DateTime To, string? Search, int? LocationId, string? Company);

public record HistoryRow(string Name, string Cpr, string Location, string? Company, string? Note, int? BadgeNo, int? SlotNo,
    DateTime CheckInAt, DateTime? CheckOutAt, string CheckInBy, string? CheckOutBy);

public static class HistoryQuery
{
    public static List<HistoryRow> Run(GateDb db, HistoryFilter f)
    {
        var from = f.From.Date;
        var to = f.To.Date.AddDays(1);
        var q = db.Visits.Include(v => v.Visitor).Include(v => v.Location)
            .Where(v => v.CheckInAt >= from && v.CheckInAt < to);

        if (Str.OrNull(f.Search) is string s)
        {
            var like = $"%{s}%"; // SQLite LIKE is case-insensitive for ASCII
            q = q.Where(v => EF.Functions.Like(v.Visitor.NameEn, like) || v.Visitor.Cpr.Contains(s)
                || (v.Visitor.NameAr != null && v.Visitor.NameAr.Contains(s)));
        }
        if (f.LocationId is int locationId) q = q.Where(v => v.LocationId == locationId);
        if (Str.OrNull(f.Company) is string c)
        {
            var like = $"%{c}%";
            q = q.Where(v => v.Company != null && EF.Functions.Like(v.Company, like));
        }

        var users = db.Users.ToDictionary(u => u.Id, u => u.DisplayName);
        return q.OrderByDescending(v => v.CheckInAt).AsEnumerable()
            .Select(v => new HistoryRow(v.Visitor.NameEn, v.Visitor.Cpr, v.Location.Display, v.Company, v.Note, v.BadgeNo, v.SlotNo,
                v.CheckInAt, v.CheckOutAt, users.GetValueOrDefault(v.CheckInByUserId, ""),
                v.CheckOutByUserId is int outBy ? users.GetValueOrDefault(outBy, "") : null))
            .ToList();
    }
}
```

```csharp
using System.IO;
using System.Text;

namespace ServiceGatePass.Services;

public static class CsvExport
{
    const string Time = "yyyy-MM-dd HH:mm";

    public static void Write(Stream stream, IEnumerable<HistoryRow> rows)
    {
        // BOM so Excel shows Arabic names correctly when the file is double-clicked.
        using var w = new StreamWriter(stream, new UTF8Encoding(encoderShouldEmitUTF8Identifier: true), leaveOpen: true);
        w.NewLine = "\r\n";
        w.WriteLine("Name,CPR,Location,Company,Note,Badge,Slot,Check-in,Check-out,Checked in by,Checked out by");
        foreach (var r in rows)
            w.WriteLine(string.Join(",", new[]
            {
                r.Name, r.Cpr, r.Location, r.Company, r.Note, r.BadgeNo?.ToString(), r.SlotNo?.ToString(),
                r.CheckInAt.ToString(Time), r.CheckOutAt?.ToString(Time), r.CheckInBy, r.CheckOutBy,
            }.Select(Cell)));
    }

    public static string Cell(string? value)
    {
        var v = value ?? "";
        // A leading = + - @ tab or CR would make Excel run the cell as a formula.
        if (v.Length > 0 && "=+-@\t\r".Contains(v[0])) v = "'" + v;
        return v.IndexOfAny([',', '"', '\n', '\r']) >= 0 ? "\"" + v.Replace("\"", "\"\"") + "\"" : v;
    }
}
```

```csharp
using Microsoft.EntityFrameworkCore;
using ServiceGatePass.Data;

namespace ServiceGatePass.Services;

public record DayCount(DateTime Day, int Count);
public record NameCount(string Name, int Count);
public record DashboardData(int VisitsToday, int InsideNow, List<DayCount> PerDay, List<NameCount> TopLocations, List<NameCount> TopCompanies);

public static class DashboardQuery
{
    public static DashboardData Load(GateDb db, DateTime today)
    {
        var day = today.Date;
        var from = day.AddDays(-29);
        // ponytail: groups 30 days of visits in memory; fine for a single gate (thousands of rows). Move grouping to SQL if it ever gets slow.
        var visits = db.Visits.Include(v => v.Location).Where(v => v.CheckInAt >= from).ToList();

        var perDay = Enumerable.Range(0, 30).Select(i => from.AddDays(i))
            .Select(d => new DayCount(d, visits.Count(v => v.CheckInAt.Date == d))).ToList();

        static List<NameCount> Top(IEnumerable<string> names) =>
            names.GroupBy(n => n).Select(g => new NameCount(g.Key, g.Count()))
                .OrderByDescending(x => x.Count).ThenBy(x => x.Name).Take(5).ToList();

        return new DashboardData(
            visits.Count(v => v.CheckInAt.Date == day),
            db.Visits.Count(v => v.CheckOutAt == null),
            perDay,
            Top(visits.Select(v => v.Location.Display)),
            Top(visits.Select(v => Str.OrNull(v.Company)).OfType<string>()));
    }
}
```

```csharp
namespace ServiceGatePass.Services;

public static class BackupService
{
    /// SQLite online backup: consistent even while the app has the database open.
    public static void Copy(string dbPath, string destPath)
    {
        using var source = new SqliteConnection($"Data Source={dbPath};Pooling=False");
        using var dest = new SqliteConnection($"Data Source={destPath};Pooling=False");
        source.Open();
        dest.Open();
        source.BackupDatabase(dest);
    }

    public static string BackupNow(string dbPath, string folder, DateTime today, int keep = 30)
    {
        Directory.CreateDirectory(folder);
        var dest = Path.Combine(folder, $"gate-{today:yyyy-MM-dd}.db");
        Copy(dbPath, dest);

        foreach (var old in Directory.GetFiles(folder, "gate-????-??-??.db").OrderDescending().Skip(keep))
            File.Delete(old);
        return dest;
    }
}
```

```csharp
    protected override void OnStartup(StartupEventArgs e)
    {
        base.OnStartup(e);
        DispatcherUnhandledException += (_, a) =>
        {
            Log.Error(a.Exception);
            MessageBox.Show(L.T("Something went wrong. Details were saved to the log.") + "\n\n" + a.Exception.Message,

            a.Handled = true;
        };

        try
        {
            Directory.CreateDirectory(DataDir);
            var existed = File.Exists(DbPath);
            bool needsSetup;
            using (var db = OpenDb())
            {

                db.Database.Migrate();
                L.Use(new SettingsStore(db).Get(SettingsStore.Language) ?? "en");
                needsSetup = !new UserService(db).AnyUsers();
            }

            if (needsSetup && new SetupWindow().ShowDialog() != true) { Shutdown(); return; }

            RunBackup();
            backupTimer.Tick += (_, _) => RunBackup();
            backupTimer.Start();
            ShowLogin();
        }
        catch (Exception ex)
        {
            // With OnExplicitShutdown a failed start would leave an invisible process; exit instead.
            Log.Error(ex);
            MessageBox.Show(ex.Message, "Service Gate Pass", MessageBoxButton.OK, MessageBoxImage.Error);
            Shutdown(1);
        }

    public void ShowLogin()
    {
        var login = new LoginWindow();
        if (login.ShowDialog() != true) { Shutdown(); return; }
        CurrentUser = login.User!;
        var main = new MainWindow();
        MainWindow = main;
        main.Show();
    }

    public static void RunBackup()
    {
        try
        {
            using var db = OpenDb();
            var folder = new SettingsStore(db).Get(SettingsStore.BackupFolder);
            BackupFolderMissing = string.IsNullOrWhiteSpace(folder);
            BackupError = null;
            if (!BackupFolderMissing) BackupService.BackupNow(DbPath, folder!, DateTime.Today);
        }
        catch (Exception ex)
        {
            Log.Error(ex);
            BackupError = string.Format(L.T("Backup failed: {0}"), ex.Message);
        }
        BackupStatusChanged?.Invoke();
    }

    public static BitmapImage? LoadImage(string? path)
    {
        if (string.IsNullOrWhiteSpace(path) || !File.Exists(path)) return null;
        var img = new BitmapImage();
        img.BeginInit();
        img.CacheOption = BitmapCacheOption.OnLoad;              // don't lock the file
        img.CreateOptions = BitmapCreateOptions.IgnoreImageCache; // pick up a replaced logo
        img.UriSource = new Uri(path);
        img.EndInit();
        img.Freeze();
        return img;
    }

    public static BitmapImage? ImageFromBase64(string? b64)
    {
        if (string.IsNullOrWhiteSpace(b64)) return null;
        var comma = b64.IndexOf(',');
        if (comma >= 0) b64 = b64[(comma + 1)..]; // tolerate "data:image/...;base64,"
        try
        {
            var img = new BitmapImage();
            img.BeginInit();
            img.CacheOption = BitmapCacheOption.OnLoad;
            img.StreamSource = new MemoryStream(Convert.FromBase64String(b64));
            img.EndInit();
            img.Freeze();
            return img;
        }
        catch (Exception ex) when (ex is FormatException or NotSupportedException) { return null; }
    }

    public static string CopyLogo(string source)
    {
        var dest = Path.Combine(DataDir, "logo" + Path.GetExtension(source).ToLowerInvariant());
        if (!string.Equals(Path.GetFullPath(source), Path.GetFullPath(dest), StringComparison.OrdinalIgnoreCase))
            File.Copy(source, dest, overwrite: true);
        return dest;
    }
```

```csharp
            db.SaveChanges();
            tx.Commit();
            DialogResult = true;
```

```csharp
    void LoadSettings()
    {
        using var db = App.OpenDb();
        var s = new SettingsStore(db);
        reader = new CardReader(App.Http, s.Get(SettingsStore.ReaderUrl) ?? CardReader.DefaultUrl);
        badgeOn = s.GetBool(SettingsStore.BadgeEnabled);
        slotOn = s.GetBool(SettingsStore.SlotEnabled);

        BadgePanel.Visibility = BadgeColumn.Visibility = badgeOn ? Visibility.Visible : Visibility.Collapsed;

    {
        using var db = App.OpenDb();

        ApplySearch();

    void ApplySearch()
    {
        var selectedId = (InsideGrid.SelectedItem as InsideRow)?.VisitId;
        var q = Search.Text.Trim();
        var rows = q == ""
            ? inside
            : inside.Where(r => r.Name.Contains(q, StringComparison.OrdinalIgnoreCase) || r.Cpr.Contains(q)
                || r.BadgeNo?.ToString() == q || r.SlotNo?.ToString() == q).ToList();
        InsideGrid.ItemsSource = rows;
        InsideGrid.SelectedItem = rows.FirstOrDefault(r => r.VisitId == selectedId) ?? (rows.Count == 1 ? rows[0] : null);
    }

        if (!slotOn) { Slot.ItemsSource = null; return; }
        using var db = App.OpenDb();
        var free = new GateService(db).FreeSlots(slotCount);
        var current = keepSelection ? Slot.SelectedItem as int? : null;
        Slot.ItemsSource = free;
        Slot.SelectedItem = current is int c && free.Contains(c) ? c : free.Count > 0 ? free[0] : null;
    }

    async void ReadCard_Click(object? sender, RoutedEventArgs? e)
    {
        ReadButton.IsEnabled = false;
        ReaderMessage.Text = L.T("Reading card…");
        try
        {
            var result = await reader.ReadAsync();
            if (result.Card is not { } card)
            {
                ReaderMessage.Text = result.Error ?? "";
                Cpr.Focus();
                return;
            }
            ReaderMessage.Text = "";
            Cpr.Text = card.Cpr;
            NameEn.Text = card.NameEn;
            nameAr = card.NameAr;
            NameArText.Text = nameAr ?? "";
            employer = card.Employer;
            Photo.Source = App.ImageFromBase64(card.PhotoBase64); // display only, never stored
            Prefill(fromCard: true);
            Locations.Focus();
        }
        finally { ReadButton.IsEnabled = true; }
    }

    void Prefill(bool fromCard)
    {
        using var db = App.OpenDb();
        var visitor = new GateService(db).FindVisitor(Cpr.Text);
        if (visitor == null)
        {
            Company.Text = employer ?? "";
            return;
        }
        if (!fromCard)
        {
            NameEn.Text = visitor.NameEn;
            nameAr = visitor.NameAr;
            NameArText.Text = nameAr ?? "";
            employer = visitor.Employer;
        }
        Company.Text = visitor.LastCompany ?? employer ?? "";
        Note.Text = visitor.LastNote ?? "";
        if (visitor.LastLocationId is int id) Locations.SelectedValue = id;

                return;
```

```csharp
using System.Windows;
using System.Windows.Controls;

using ServiceGatePass.Services;

namespace ServiceGatePass.Views;

public partial class HistoryView : UserControl
{
    const string Time = "yyyy-MM-dd HH:mm";
    List<HistoryRow> rows = [];

    public HistoryView()
    {
        InitializeComponent();
        FromDate.SelectedDate = ToDate.SelectedDate = DateTime.Today;
        using var db = App.OpenDb();
        var locations = new List<LocationItem> { new(0, L.T("All locations")) };
        locations.AddRange(db.Locations.OrderBy(l => l.SortOrder).ToList().Select(l => new LocationItem(l.Id, l.Display)));
        LocationBox.ItemsSource = locations;
        LocationBox.SelectedIndex = 0;
        Run();
    }

    void Run()
    {
        using var db = App.OpenDb();
        rows = HistoryQuery.Run(db, new HistoryFilter(
            FromDate.SelectedDate ?? DateTime.Today,
            ToDate.SelectedDate ?? DateTime.Today,
            SearchBox.Text,
            LocationBox.SelectedValue is int id && id != 0 ? id : null,
            CompanyBox.Text));
        ResultsGrid.ItemsSource = rows;
        CountText.Text = string.Format(L.T("{0} visits"), rows.Count);
    }

    void Show_Click(object sender, RoutedEventArgs e) => Run();

    void Export_Click(object sender, RoutedEventArgs e)
    {
        var dlg = new SaveFileDialog { Filter = "CSV (*.csv)|*.csv", FileName = $"gate-history-{DateTime.Now:yyyyMMdd-HHmm}.csv" };
        if (dlg.ShowDialog() != true) return;
        using var file = File.Create(dlg.FileName);
        CsvExport.Write(file, rows);
    }

    void Print_Click(object sender, RoutedEventArgs e)
    {
        var dlg = new PrintDialog();
        if (dlg.ShowDialog() != true) return;
        string hotel;
        using (var db = App.OpenDb()) hotel = new SettingsStore(db).Get(SettingsStore.HotelName) ?? "";
        var title = $"{hotel} — {L.T("Gate history")} {FromDate.SelectedDate:yyyy-MM-dd} – {ToDate.SelectedDate:yyyy-MM-dd}";
        var doc = BuildDocument(title, dlg.PrintableAreaWidth);
        dlg.PrintDocument(((IDocumentPaginatorSource)doc).DocumentPaginator, L.T("Gate history"));
    }

    FlowDocument BuildDocument(string title, double width)
    {
        var doc = new FlowDocument
        {
            PageWidth = width,
            ColumnWidth = width,
            FontSize = 11,
            PagePadding = new Thickness(40),
            FlowDirection = L.IsArabic ? FlowDirection.RightToLeft : FlowDirection.LeftToRight,
        };
        doc.Blocks.Add(new Paragraph(new Run(title)) { FontSize = 16, FontWeight = FontWeights.Bold });

        string[] headers = [L.T("Name"), L.T("CPR"), L.T("Location"), L.T("Company"), L.T("In"), L.T("Out")];
        var table = new Table { CellSpacing = 0 };
        foreach (var _ in headers) table.Columns.Add(new TableColumn());
        var group = new TableRowGroup();
        table.RowGroups.Add(group);
        group.Rows.Add(Row(headers, bold: true));
        foreach (var r in rows)
            group.Rows.Add(Row([r.Name, r.Cpr, r.Location, r.Company ?? "", r.CheckInAt.ToString(Time),
                r.CheckOutAt?.ToString(Time) ?? L.T("Inside")], bold: false));
        doc.Blocks.Add(table);
        return doc;

        static TableRow Row(string[] cells, bool bold)
        {
            var row = new TableRow();
            foreach (var cell in cells)
                row.Cells.Add(new TableCell(new Paragraph(new Run(cell)))
                {
                    FontWeight = bold ? FontWeights.Bold : FontWeights.Normal,
                    Padding = new Thickness(2),
                    BorderBrush = Brushes.Gray,
                    BorderThickness = new Thickness(0, 0, 0, 0.5),
                });
            return row;
        }
    }
```

```csharp
using System.Windows;
using System.Windows.Controls;
using System.Windows.Media;

namespace ServiceGatePass.Views;

public partial class SettingsView : UserControl

    string? newLogo;

    public SettingsView()
    {
        InitializeComponent();
        using var db = App.OpenDb();
        var s = new SettingsStore(db);
        HotelNameBox.Text = s.Get(SettingsStore.HotelName) ?? "";
        LogoImage.Source = App.LoadImage(s.Get(SettingsStore.LogoPath));
        BadgeBox.IsChecked = s.GetBool(SettingsStore.BadgeEnabled);
        SlotBox.IsChecked = s.GetBool(SettingsStore.SlotEnabled);
        SlotCountBox.Text = s.GetInt(SettingsStore.SlotCount, 50).ToString();
        BackupBox.Text = s.Get(SettingsStore.BackupFolder) ?? "";
        ReaderBox.Text = s.Get(SettingsStore.ReaderUrl) ?? CardReader.DefaultUrl;
        LoadLocations(db);
    }

    void LoadLocations(GateDb db)
    {
        var selectedId = (LocationsList.SelectedItem as Location)?.Id;
        var list = db.Locations.OrderBy(l => l.SortOrder).ToList();
        LocationsList.ItemsSource = list;
        LocationsList.SelectedItem = list.FirstOrDefault(l => l.Id == selectedId);
    }

    void Msg(string text, bool error)
    {
        MessageText.Text = text;
        MessageText.Foreground = error ? Brushes.DarkRed : Brushes.DarkGreen;
    }

    void ChooseLogo_Click(object sender, RoutedEventArgs e)
    {
        var dlg = new OpenFileDialog { Filter = "Images|*.png;*.jpg;*.jpeg;*.bmp" };
        if (dlg.ShowDialog() != true) return;
        newLogo = dlg.FileName;
        LogoImage.Source = App.LoadImage(newLogo);
    }

    void ChooseFolder_Click(object sender, RoutedEventArgs e)
    {
        var dlg = new OpenFolderDialog();
        if (dlg.ShowDialog() == true) BackupBox.Text = dlg.FolderName;
    }

    void Save_Click(object sender, RoutedEventArgs e)
    {
        if (string.IsNullOrWhiteSpace(HotelNameBox.Text)) { Msg(L.T("Hotel name is required."), true); return; }
        if (!int.TryParse(SlotCountBox.Text.Trim(), out var slots) || slots < 1 || slots > 500)
        { Msg(L.T("Slot count must be between 1 and 500."), true); return; }
        if (!Uri.TryCreate(ReaderBox.Text.Trim(), UriKind.Absolute, out _)) { Msg(L.T("Card reader URL is not valid."), true); return; }

        using (var db = App.OpenDb())
        {
            var s = new SettingsStore(db);
            s.Set(SettingsStore.HotelName, HotelNameBox.Text.Trim());
            if (newLogo != null) s.Set(SettingsStore.LogoPath, App.CopyLogo(newLogo));
            s.Set(SettingsStore.BadgeEnabled, BadgeBox.IsChecked == true ? "1" : "0");
            s.Set(SettingsStore.SlotEnabled, SlotBox.IsChecked == true ? "1" : "0");
            s.Set(SettingsStore.SlotCount, slots.ToString());
            s.Set(SettingsStore.BackupFolder, Str.OrNull(BackupBox.Text));
            s.Set(SettingsStore.ReaderUrl, ReaderBox.Text.Trim());
        }
        newLogo = null;
        App.RunBackup(); // runs now so the banner clears (or shows the error) right away
        (Window.GetWindow(this) as MainWindow)?.RefreshHeader();
        Msg(L.T("Settings saved."), false);
    }

    void LocationsList_SelectionChanged(object sender, SelectionChangedEventArgs e)
    {
        if (LocationsList.SelectedItem is not Location loc) return;
        LocNameBox.Text = loc.Name;
        LocNameArBox.Text = loc.NameAr ?? "";
    }

    /// Location edits save immediately; the Gate tab reloads them when it is shown.
    void WithSelected(Action<GateDb, Location> change)
    {
        if (LocationsList.SelectedItem is not Location selected) { Msg(L.T("Select a location first."), true); return; }
        using var db = App.OpenDb();
        change(db, db.Locations.Find(selected.Id)!);
        db.SaveChanges();
        LoadLocations(db);
    }

    void AddLocation_Click(object sender, RoutedEventArgs e)
    {
        if (Str.OrNull(LocNameBox.Text) is not string name) { Msg(L.T("Location name is required."), true); return; }
        using var db = App.OpenDb();
        db.Locations.Add(new Location
        {
            Name = name,
            NameAr = Str.OrNull(LocNameArBox.Text),
            SortOrder = (db.Locations.Max(l => (int?)l.SortOrder) ?? -1) + 1,
        });
        db.SaveChanges();
        LoadLocations(db);
        LocNameBox.Text = LocNameArBox.Text = "";
    }

    void RenameLocation_Click(object sender, RoutedEventArgs e)
    {
        if (Str.OrNull(LocNameBox.Text) is not string name) { Msg(L.T("Location name is required."), true); return; }
        WithSelected((_, loc) => { loc.Name = name; loc.NameAr = Str.OrNull(LocNameArBox.Text); });
    }

    void Move(int direction) => WithSelected((db, loc) =>
    {
        var list = db.Locations.OrderBy(l => l.SortOrder).ToList();
        var i = list.FindIndex(l => l.Id == loc.Id);
        var j = i + direction;
        if (j < 0 || j >= list.Count) return;
        (list[i], list[j]) = (list[j], list[i]);
        for (var k = 0; k < list.Count; k++) list[k].SortOrder = k;
    });

    void Up_Click(object sender, RoutedEventArgs e) => Move(-1);
    void Down_Click(object sender, RoutedEventArgs e) => Move(1);
    void ToggleLocation_Click(object sender, RoutedEventArgs e) => WithSelected((_, loc) => loc.IsActive = !loc.IsActive);
}
```

```csharp
using System.Windows;
using System.Windows.Controls;
using System.Windows.Media;
using ServiceGatePass.Data;
using ServiceGatePass.Services;

namespace ServiceGatePass.Views;

public partial class UsersView : UserControl
{
    public UsersView()
    {
        InitializeComponent();
        Load();
    }

    void Load()
    {
        var selectedId = (UsersGrid.SelectedItem as User)?.Id;
        using var db = App.OpenDb();
        var users = new UserService(db).All();
        UsersGrid.ItemsSource = users;
        UsersGrid.SelectedItem = users.FirstOrDefault(u => u.Id == selectedId);
    }

    void Msg(string text, bool error)
    {
        MessageText.Text = text;
        MessageText.Foreground = error ? Brushes.DarkRed : Brushes.DarkGreen;
    }

    bool Act(Action<UserService> action)
    {
        try
        {
            using (var db = App.OpenDb()) action(new UserService(db));
            Load();
            Msg(L.T("Done."), false);
            return true;
        }
        catch (GateException ex)
        {
            Msg(ex.Message, true);
            return false;
        }
    }

    void WithSelected(Action<UserService, User> action)
    {
        if (UsersGrid.SelectedItem is not User user) { Msg(L.T("Select a user first."), true); return; }
        Act(s => action(s, user));
    }

    void Add_Click(object sender, RoutedEventArgs e)
    {
        if (Act(s => s.Create(UsernameBox.Text, DisplayNameBox.Text, PasswordInput.Password, (Role)RoleBox.SelectedIndex)))
        {
            UsernameBox.Text = DisplayNameBox.Text = "";
            PasswordInput.Clear();
        }
    }

    void Reset_Click(object sender, RoutedEventArgs e)
    {
        WithSelected((s, u) => s.ResetPassword(u.Id, PasswordInput.Password));
        PasswordInput.Clear();
    }

    void Toggle_Click(object sender, RoutedEventArgs e) => WithSelected((s, u) => s.SetActive(u.Id, !u.IsActive));
    void MakeAdmin_Click(object sender, RoutedEventArgs e) => WithSelected((s, u) => s.SetRole(u.Id, Role.Admin));
    void MakeGate_Click(object sender, RoutedEventArgs e) => WithSelected((s, u) => s.SetRole(u.Id, Role.Gate));
}
```

```markdown
# Installing Service Gate Pass

## 1. Card reader service (once per PC)
1. Copy the `SCardReadServer` folder to the PC.
2. Run `SCardReadServer.exe` — this installs and starts the Windows service "CIO GCC CardRead Server".
3. New Bahrain cards: stop the service, replace its SDK files with the ones from
   `Bahrain Smart Card SDK-V1.1.rar`, start the service again.
4. If a "CAS policy" `NotSupportedException` appears, open
   `Bahrain Smart Card SDK\DotNet\Extensions\BAH`, and for each file:
   right-click → Properties → tick **Unblock** → OK.
5. Check: with a card inserted, the app's **Read card** button fills the form.

## 2. The app
1. Run `ServiceGatePass-Setup-<version>.exe` as an administrator.
2. On first start, fill in the hotel name, logo, locations and the first admin account.
3. Sign in as the admin → **Settings** → choose a **Backup folder** (a USB drive or network
   share) → **Save**. A copy is made immediately and then every day; the newest 30 are kept.
4. **Users** → add one account per guard (role: Gate staff).

## Where data lives
- Database: `C:\ProgramData\ServiceGatePass\gate.db`
- Error logs: `C:\ProgramData\ServiceGatePass\logs\`
- Uninstalling the app does **not** delete the database.

## If the PC fails
Use the paper book. On the replacement PC, install the app, close it, copy the newest
`gate-YYYY-MM-DD.db` from the backup folder to `C:\ProgramData\ServiceGatePass\gate.db`, then start the app.
```
